## Topic

Побудова рішення розпізнавання тексту із застосуванням ШІ

## Objective

Набути практичних навичок побудови конвеєра оптичного розпізнавання тексту
(OCR) із застосуванням нейромережевих моделей: від формування набору даних з еталонною
розміткою та попередньої обробки зображень до порівняння кількох інструментів
розпізнавання, кількісного оцінювання якості за метриками CER і WER, побудови та
обґрунтованої інтерпретації графіків метрик, аналізу помилок і перетворення розпізнаного
тексту на структуровані дані.
